# STM32F103 Timer (TIM) Driver

A lightweight **bare-metal Timer (TIM) driver** for the STM32F103xx microcontroller family, implemented entirely using **CMSIS** and **direct register programming**.

This driver provides a simple yet powerful interface for configuring STM32 general-purpose and advanced timers without relying on STM32 HAL or LL libraries.

---

# Features

- ✅ TIM1, TIM2, TIM3 and TIM4 support
- ✅ Basic timer initialization
- ✅ Automatic timer clock enable
- ✅ Configurable Prescaler (PSC)
- ✅ Configurable Auto Reload Register (ARR)
- ✅ Automatic timer frequency calculation
- ✅ Start / Stop timer
- ✅ Read / Write counter value
- ✅ Update Event (Overflow) Interrupt
- ✅ Output Compare
- ✅ PWM Generation (PWM1 & PWM2)
- ✅ Runtime PWM duty cycle update
- ✅ Duty cycle helper (0–100%)
- ✅ Input Capture
- ✅ Rising / Falling edge selection
- ✅ Capture / Compare Interrupts
- ✅ Automatic ISR callback dispatch
- ✅ Header-only implementation
- ✅ CMSIS Register-Level Programming

# Example

This example demonstrates two timers operating simultaneously.

### TIM2

- Output Compare
- Toggle Mode
- Generates a square wave on **PA0**

### TIM3

- Input Capture
- Rising Edge Detection
- Captures the timestamp of the signal generated by TIM2

```
PA0 (TIM2_CH1)
      │
      │ Jumper Wire
      ▼
PA6 (TIM3_CH1)
```

Whenever TIM2 toggles PA0, TIM3 captures the timer count on PA6.

---

# Example Code

```c
tim_init_t tim2_cfg =
{
    .instance = TIM2,
    .prescaler = 7200,
    .period = 10000,
    .auto_reload_preload = 0
};

tim_init(&tim2_cfg);

tim_oc_channel_init(
    TIM2,
    TIM_CHANNEL_1,
    TIM_OCMODE_TOGGLE,
    0);

tim_start(TIM2);
```

# Timer Frequency

The helper

```c
tim_set_frequency()
```

automatically calculates suitable PSC and ARR values for a requested timer frequency.

Example

```c
tim_set_frequency(TIM2, 1000);
```

Generates approximately a **1 kHz** timer.

---

# PWM Duty Cycle

Instead of manually calculating CCR values,

```c
tim_pwm_duty_from_percent(TIM2, 75);
```

returns the CCR value corresponding to **75% duty cycle**.

# GPIO Configuration

The timer driver **does not configure GPIO pins automatically**.

Configure pins before initializing channels.

### Output Compare / PWM

```c
GPIO_MODE_AF_PP_50MHZ
```

### Input Capture

```c
GPIO_MODE_INPUT_FLOATING
```
